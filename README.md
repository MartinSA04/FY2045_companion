# FY2045 — Kvantemekanikk I

Interaktiv studieguide for [FY2045](https://www.ntnu.no/studier/emner/FY2045)
ved NTNU: **[kvante.martinsundal.no](https://kvante.martinsundal.no)** — moduler med quiz, flashcards,
formelsamling og begreper.

Bygget på [StudyCompanion](https://github.com/MartinSA04/StudyCompanion);
dette repoet inneholder kun innhold (`content/`).

## Kjør lokalt

```bash
pnpm install
pnpm dev
```
