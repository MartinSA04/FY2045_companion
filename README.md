# FY2045 Kvantemekanikk I

Interaktivt kompendium i [FY2045](https://www.ntnu.no/studier/emner/FY2045) ved NTNU:
moduler med quiz, flashcards, formelsamling og begreper. Les det på
**[kvante.martinsundal.no](https://kvante.martinsundal.no)**.

Bygget på [StudyCompanion](https://github.com/MartinSA04/StudyCompanion);
dette repoet inneholder kun innhold (`content/`).

## Kjør lokalt

```bash
pnpm install
pnpm dev
```
